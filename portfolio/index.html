Projects

  • Throughout this course, I completed a series of structured assignments designed to help me build a strong foundation in JavaScript and front-end web development. Each assignment focused on a specific concept and allowed me to apply both theory and practice in a progressive way. I began with the Repository Submission Assignment and the Folder Structure Assignment, where I learned how to properly organize a project, create clear directory structures, and manage my work using GitHub. This helped me understand the importance of clean project organization and version control. Next, I worked on basic output methods such as the window.alert() Method Assignment and the document.write() Method Assignment, which introduced me to displaying information dynamically in the browser and understanding how JavaScript interacts with HTML. In the Variable Assignment, Multiple Variables Assignment, and String Assignment, I learned how to declare variables, store data, and work with text values. These exercises helped me understand data types, variable scope, and how to manage information within a program. With the Escape Character Assignment and the Concatenation Assignment, I practiced manipulating strings, combining text and variables, and correctly handling special characters inside strings. The Comment Assignment taught me how to write clear comments in my code, improving readability and making my projects easier to understand for instructors and other developers. Finally, in the Basic JavaScript Projects Assignment, I applied all the concepts I had learned by building small functional projects. These projects combined variables, strings, output methods, and basic logic to demonstrate my understanding of core JavaScript principles.
